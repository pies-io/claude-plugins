---
name: pies-explain
description: Ask a PIES Studio app what it does (screens, tables, events, functions) in plain sentences.
---

Use the `pies` MCP tools `get_app_summary`, then `get_screen_summary` for each screen and `describe_wiring` for the events the user asks about. Answer in plain sentences: what each screen shows, which tables it reads and writes, what each button does. Use the PIES words: Events, Functions, Tables, Used by, Calls.
